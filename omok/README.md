# 오목의 전설

DB 없이 동작하는 실시간 2인 오목입니다. Node.js 서버 하나가 방, 접속 세션, 오목판을 메모리에 보관하고 Socket.IO로 동기화합니다. 화면은 별도 빌드 없이 제공됩니다.

UI는 각진 박스와 굵은 테두리, 선명한 노란색 선택 표시, 기본 글꼴을 사용하는 투박한 웹 게임방 스타일입니다. 도트 표현은 캐릭터 아바타에 사용합니다.

## 실행

Node.js 22 이상에서 실행하세요.

```powershell
cd C:\Users\JUNGDH\Desktop\kimjc\omok
npm install
npm start
```

접속 주소는 **http://localhost:3000** 입니다. 의존성 설치가 끝난 뒤에는 `node server.js`로도 실행할 수 있습니다.

## 화면 구성

- **프로필 선택 `/profile`**: 주찬·경후·강희·용환 중 이름과 도트 아바타가 고정된 프로필을 고릅니다. 이름 입력과 별도 아바타 변경은 지원하지 않습니다.
- **방 생성·조회 `/lobby`**: 선택한 프로필을 확인하고, 방 만들기·공개 방 목록·초대 코드 참가를 이용합니다. 여기서 프로필 선택 화면으로 돌아갈 수 있습니다.
- **게임 `/game/방코드`**: 오목판, 상대방, 현재 차례, 초대 코드와 대국 버튼만 표시합니다. 방에서 나가면 대기실로 돌아옵니다.

각 주소를 새로고침해도 화면을 열 수 있습니다. 프로필을 고르지 않은 손님은 프로필 화면으로 안내하며, 참여 중인 방이 있으면 해당 게임으로 복귀합니다. 화면을 옮겨도 소켓 연결은 유지됩니다.

## 두 사람으로 테스트하기

1. 브라우저 탭 두 개에서 접속합니다. 각 탭이 별도의 손님입니다.
2. 첫 탭에서 주찬·경후·강희·용환 중 프로필을 고른 뒤 대기실로 들어가 방을 만듭니다. 게임 화면으로 자동 이동합니다.
3. 두 번째 탭에서도 프로필을 고른 뒤 대기실 목록의 방을 누르거나 6자리 초대 코드를 입력합니다. 초대 링크를 사용해도 됩니다. 초대받은 코드는 프로필을 선택하거나 새로고침하는 동안에도 유지됩니다. 상대가 들어오면 양쪽 화면에 시작 안내 모달이 뜹니다. 안내를 닫으면 자신의 차례에 착수할 수 있습니다.
4. 흑부터 번갈아 둡니다. 오목판의 자리를 선택한 다음 **착수 버튼**을 눌러 확정합니다.
5. 5개 이상 연결하면 승리하고 각자의 화면에 승리·패배 결과 모달이 뜹니다. 결과 모달이나 오목판 아래에서 양쪽이 **한판더**를 누르면 흑·백을 바꿔 새 대국을 시작합니다.
6. 새로고침하면 같은 탭의 대국으로 복귀합니다. 연결이 끊긴 상대방에게는 30초의 복귀 시간이 주어집니다. 그동안 착수는 멈추며, 시간이 지나면 연결을 유지한 사람이 승리합니다.

규칙은 **15×15 자유룰**입니다. 흑이 먼저 두고, 장목도 승리로 인정하며, 삼삼·사사 같은 금수는 적용하지 않습니다. 빈자리가 없으면 무승부입니다. 방향키로 오목판의 초점을 옮기고 Enter로 위치를 선택한 뒤 Tab으로 착수 버튼에 이동할 수 있습니다.

## 시작·결과 모달

시작, 승리·패배, 무승부, 기권, 상대 퇴장, 연결 복귀 시간 초과를 상황별 제목·본문으로 표시합니다. 모달과 각 페이지에는 추가 설명 문장을 표시하지 않습니다. 시작 모달은 **시작** 버튼 하나로 진행하며, 닫기·구경하기·Escape로 넘길 수 없습니다. 결과 모달에서는 재대국 요청 또는 닫기가 가능합니다. 재대국 문구는 승자에게 **한판더 · 한번 더 쳐바르기**, 패자에게 **한판더 · 한번 더 쳐발리기**로 표시합니다. 흑·백과 현재 차례는 참가자 정보와 게임 상태에 표시하며, 잠깐의 연결 끊김은 재접속 대기 시간만 표시합니다.

모달은 판마다 한 번씩 표시하며 같은 탭의 새로고침·재접속 때 반복하지 않습니다. 새 상대가 들어오거나 재대국이 성립하면 다음 판으로 처리합니다. 문구는 `public/game-messages.js`에서 바꿀 수 있습니다. 시작 모달은 각 사용자의 화면 안내이며, 서버는 상대가 입장한 시점부터 대국을 진행합니다.

## 자동 테스트

```powershell
npm test
```

또는 프로젝트 폴더에서 `node --test`를 실행하세요. 승패·무승부 판정과 실제 Socket.IO 클라이언트 간의 방 참가, 상태 동기화, 잘못된 착수 차단, 재접속, 시간 초과, 기권, 재대국, 방 격리를 검증합니다. jsdom으로 실제 화면 코드를 실행해 프로필 선택·페이지 이동·초대 코드 유지·새로고침 복귀·두 화면 간 착수도 검증합니다. jsdom은 브라우저의 시각적 배치를 검증하지는 않습니다.

## 서버에서 실행하기

이 프로젝트는 **계속 실행되는 Node.js 프로세스 한 개**가 필요합니다. 정적 파일 호스팅만으로는 대전이 동작하지 않습니다.

```powershell
$env:PORT = '3000'
node server.js
```

기본 바인딩은 `0.0.0.0`입니다. 같은 네트워크의 다른 기기는 서버 PC의 IP와 포트로 접속할 수 있습니다. 운영 환경에서는 도메인 앞에 HTTPS 리버스 프록시를 두고 `/socket.io/`의 WebSocket 업그레이드 및 폴링 요청을 이 Node 서버로 전달하세요. `Host`를 보존해야 같은 출처 확인이 통과합니다. 프로세스 수는 1개로 유지하세요.

## 저장과 범위

- 방과 대국은 서버 재시작 시 초기화됩니다. 방은 30분 동안 활동이 없으면 닫힙니다.
- 선택한 프로필 ID는 `localStorage`에, 탭별 복귀 토큰과 대기 중인 초대 코드는 `sessionStorage`에 저장합니다. 이름과 아바타는 프로필 ID에 고정되며, 클라이언트가 다른 이름이나 아바타를 보내도 서버의 고정값을 적용합니다. 브라우저 저장이 제한되어도 대국은 가능하지만 새로고침 후 복귀는 보장되지 않습니다.
- 이름 선택은 회원 인증이 아닙니다. 여러 사람이 같은 이름을 선택할 수 있으며, 각 탭의 게임 참가자는 별도 세션으로 구분합니다. 서버도 허용된 이름만 적용하고, 방 안에서는 프로필 변경을 막습니다.
- 공개 방 목록, 비공개 초대 방, 착수 확인, 마지막 수·승리 연결 표시, 기권, 나가기, 재대국을 지원합니다.
- 회원가입, 전적, 랭킹, 이미지 업로드, 자동 매칭, 렌주룰은 이번 버전에 포함하지 않았습니다.
- 게스트 세션과 기본 요청 제한을 적용했습니다. 대규모 공개 서비스로 확장할 때는 서버 간 상태 공유, IP별 접속 제한과 운영 모니터링을 추가해야 합니다.

## 도트 아바타

아바타는 `public/assets/avatars/`의 투명 PNG를 사용합니다. 주찬은 초록색 갓파 캐릭터, 경후는 진격의 거인의 초대형 거인, 강희는 근육맨 캐릭터, 용환은 진한 눈썹·헝클어진 갈색 머리·주황색 옷깃의 캐릭터입니다. 모두 정면으로 서 있는 도트 스타일이며 프로필 선택·대기실·대국에 동일하게 표시합니다.

강희는 이마의 `肉` 표시와 빨간 레슬링 복장·부츠를 갖춘 근육맨 캐릭터입니다. 다른 두 아바타와 어울리도록 픽셀을 굵게 하고 근육·명암 묘사를 단순화했으며, 몸통과 다리를 짧게 줄여 전체 높이를 맞췄습니다. 이름과 아바타의 연결은 그대로 고정됩니다.

생성 방식과 사용한 프롬프트는 `assets/avatar-prompts.json`에 기록합니다.
