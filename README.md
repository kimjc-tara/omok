# 타라미니게임천국

게임을 골라 입장하는 미니게임 홈, 실시간 2인 오목의 전설, 2~4인 섯다입니다. Node.js 서버 하나가 방, 접속 세션, 게임과 방 채팅을 메모리에 보관하고 Socket.IO로 동기화합니다. 화면은 별도 빌드 없이 제공됩니다.

UI는 각진 박스와 굵은 테두리, 선명한 노란색 선택 표시, 기본 글꼴을 사용하는 투박한 웹 게임방 스타일입니다. 도트 표현은 캐릭터 아바타에 사용합니다.

## 실행

Node.js 22 이상에서 실행하세요.

```powershell
cd C:\Users\JUNGDH\Desktop\kimjc\omok
npm install
npm start
```

접속 주소는 **http://localhost:3000** 입니다. 의존성 설치가 끝난 뒤에는 `node server.js`로도 실행할 수 있습니다.

## 화면 구성

- **홈 `/`**: 처음 입장하면 프로필부터 선택하고 타라미니게임천국의 게임 선택 화면으로 이동합니다. 오목의 전설과 섯다는 입장 가능하며 체스·다른 그림 찾기는 준비 중으로 표시합니다. 선택한 프로필은 홈에서 확인·변경할 수 있습니다.
- **오목 입구 `/omok`**: 선택한 프로필이 있으면 대국실로, 없으면 프로필 선택으로 이동합니다. 기존 `/profile`, `/lobby`, `/game/방코드` 직접 접속도 유지합니다.
- **프로필 선택 `/profile`**: 주찬·경후·강희·용환·동현·지원·민서 중 이름과 도트 아바타가 고정된 공통 프로필을 고릅니다. 기본적으로 선택 후 게임 선택 홈으로 이동하며, 오목에 직접 접속하거나 초대받은 경우 대기실로 이어집니다. 이름 입력과 별도 아바타 변경은 지원하지 않습니다.
- **방 생성·조회 `/lobby`**: 선택한 프로필을 확인하고, 방 만들기·공개 방 목록·초대 코드 참가를 이용합니다. 여기서 프로필 선택 화면으로 돌아갈 수 있습니다.
- **게임 `/game/방코드`**: 오목판, 상대방, 현재 차례, 초대 코드와 대국 버튼만 표시합니다. 방에서 나가면 대기실로 돌아옵니다.
- **섯다 `/seotda`**: 섯다 방 생성·목록·코드 참가 화면입니다. 기존에 선택한 공통 프로필을 사용합니다. 선택한 프로필이 없으면 먼저 고릅니다.
- **섯다 대전 `/seotda/game/방코드`**: 최대 4인 테이블, 내 패와 족보, 가상 칩 베팅, 결과와 채팅을 표시합니다.

각 주소를 새로고침해도 화면을 열 수 있습니다. 프로필을 고르지 않은 손님은 프로필 화면으로 안내하며, 참여 중인 방이 있으면 해당 게임으로 복귀합니다. 화면을 옮겨도 소켓 연결은 유지됩니다.

## 두 사람으로 테스트하기

1. 브라우저 탭 두 개에서 접속해 각각 프로필을 고른 뒤 홈의 **오목의 전설**을 선택합니다. 각 탭이 별도의 손님입니다.
2. 첫 탭에서 대기실에 방을 만듭니다. 게임 화면으로 자동 이동합니다.
3. 두 번째 탭에서 대기실 목록의 방을 누르거나 6자리 초대 코드를 입력합니다. 초대 링크를 사용해도 됩니다. 초대받은 코드는 프로필을 선택하거나 새로고침하는 동안에도 유지됩니다. 상대가 들어오면 양쪽 화면에 시작 안내 모달이 뜹니다. 안내를 닫으면 자신의 차례에 착수할 수 있습니다.
4. 흑부터 번갈아 둡니다. 오목판의 자리를 선택한 다음 **착수 버튼**을 눌러 확정합니다.
5. 5개 이상 연결하면 승리하고 각자의 화면에 승리·패배 결과 모달이 뜹니다. 결과 모달이나 오목판 아래에서 양쪽이 **한판더**를 누르면 흑·백을 바꿔 새 대국을 시작합니다.
6. 새로고침하면 같은 탭의 대국으로 복귀합니다. 연결이 끊긴 상대방에게는 30초의 복귀 시간이 주어집니다. 그동안 착수는 멈추며, 시간이 지나면 연결을 유지한 사람이 승리합니다.

규칙은 **15×15 자유룰**입니다. 흑이 먼저 두고, 장목도 승리로 인정하며, 삼삼·사사 같은 금수는 적용하지 않습니다. 빈자리가 없으면 무승부입니다. 방향키로 오목판의 초점을 옮기고 Enter로 위치를 선택한 뒤 Tab으로 착수 버튼에 이동할 수 있습니다.

## 시작·결과 모달

시작, 승리·패배, 무승부, 기권, 상대 퇴장, 연결 복귀 시간 초과를 상황별 제목·본문으로 표시합니다. 모달과 각 페이지에는 추가 설명 문장을 표시하지 않습니다. 시작 모달은 **시작** 버튼 하나로 진행하며, 닫기·구경하기·Escape로 넘길 수 없습니다. 결과 모달에서는 재대국 요청 또는 닫기가 가능합니다. 재대국 문구는 승자에게 **한판더 · 한번 더 쳐바르기**, 패자에게 **한판더 · 한번 더 쳐발리기**로 표시합니다. 흑·백과 현재 차례는 참가자 정보와 게임 상태에 표시하며, 잠깐의 연결 끊김은 재접속 대기 시간만 표시합니다.

모달은 판마다 한 번씩 표시하며 같은 탭의 새로고침·재접속 때 반복하지 않습니다. 새 상대가 들어오거나 재대국이 성립하면 다음 판으로 처리합니다. 문구는 `public/game-messages.js`에서 바꿀 수 있습니다. 시작 모달은 각 사용자의 화면 안내이며, 서버는 상대가 입장한 시점부터 대국을 진행합니다.

## 방 채팅

대국실에서 대기·대전·게임 종료 후 채팅할 수 있습니다. 같은 방 사용자에게만 전송하며 서버가 선택된 프로필의 이름을 붙입니다. 한 메시지는 200자까지이고 0.7초 이내 연속 전송은 제한합니다. HTML은 실행하지 않고 일반 문자로 표시합니다.

최근 50개 메시지는 방 메모리에 보관해 같은 방에 입장하거나 재접속할 때 복구합니다. 방에서 나가면 화면의 기록은 지워지고, 방 삭제 또는 서버 재시작 시 해당 기록도 사라집니다. 헤더의 홈 링크는 현재 방을 나간 뒤 게임 선택 화면으로 이동하며, 진행 중인 대국에서는 나가기 확인을 거칩니다.

## 섯다

홈에서 **섯다**를 선택하고 방을 만들거나 공개 방 목록·초대 코드로 참가합니다. 빈자리가 있으면 진행 중인 방에도 들어갈 수 있으며, 입장한 사람은 현재 판을 관전하고 다음 판부터 패를 받습니다. 방장은 접속한 2~4명이 모이면 첫 **게임 시작**을 누릅니다. 콜로 베팅이 끝나면 먼저 패와 족보를 공개하고 1.5초 뒤 중앙에 결과를 표시합니다. 이때 잔고와 손익도 정산된 금액으로 바뀌며, 결과 표시 후 2초 뒤 다음 판을 자동 시작합니다. 다이로 끝난 판은 결과를 바로 표시합니다.

입장·퇴장으로 인원이 바뀌면 자동 시작 예약을 취소합니다. 퇴장은 해당 자리의 다이로 처리하고 남은 참가자가 계속 진행하며, 한 명만 남으면 그 사람이 승리합니다. 현재 판이 끝난 뒤 방장 또는 직전 판에서 칩을 딴 사람이 **게임 시작**을 눌러야 다시 진행합니다. 이 버튼을 누르면 선택된 **자동 다음 판** 설정에 따라 이후 판이 이어집니다. 재접속 유예 동안에는 대국 참가자의 베팅을 멈추며, 다음 판을 기다리는 관전자의 연결 끊김은 현재 베팅을 막지 않습니다. 방장이 나가면 남은 사람에게 방장을 넘깁니다.

1~10월 각 2장, 총 20장 중 각자 2장씩 받습니다. 덱에서 자리별로 한 장씩 날아오고 내 패가 뒤집히는 애니메이션을 사용하며, 내 패 바로 아래에 족보를 표시합니다. 옆의 족보판은 강한 순서대로 표시하고 내 족보를 강조하며 바로 위·아래 족보를 알려줍니다. 서버 판정과 족보판은 `public/seotda-ranks.js`의 순서를 공유합니다. 새로고침·재접속 시 같은 패로 복귀하며 배분 애니메이션을 반복하지 않습니다. 동작 줄이기 설정에서는 애니메이션을 생략합니다.

이번 버전은 **두 장을 모두 받고 한 차례의 베팅을 진행하는 간단 룰**입니다. 광땡, 땡, 알리·독사·구삥·장삥·장사·세륙, 갑오·끗·망통을 판정합니다. 구사·멍텅구리 구사·암행어사·땡잡이와 땡값은 적용하지 않으며, 게임 안의 **족보 / 규칙**에서 범위를 확인할 수 있습니다. 기본 조합과 순서는 [공개특허 자료의 족보 설명(11~12쪽)](https://patentimages.storage.googleapis.com/pdfs/75b5885dc7202c37e52f/1020140161423.pdf)을 참고했습니다.

접속 세션마다 가상 칩 1,000개로 시작합니다. 기본 참가 칩은 10개이며 **체크·콜·+10 레이즈·+50 레이즈·올인·다이**를 선택합니다. 레이즈 횟수 제한 없이 남은 칩 범위에서 계속 올릴 수 있고, **올인**은 남은 칩 전체를 베팅합니다. 잔액이 콜보다 적으면 올인 콜입니다. 행동과 금액은 나와 상대 프로필 위의 말풍선으로 표시합니다. 같은 족보는 나눠 갖고 올인은 기여한 범위의 팟만 정산합니다. 미호출 초과분은 돌려줍니다. 테이블 위에 **내 잔고·누적 손익·이번 판 베팅/손익**을 표시합니다. 잔고와 누적 손익은 같은 세션의 다음 판·방 이동·프로필 변경·새로고침에도 이어집니다. 홈과 게임 사이를 이동할 때는 서버가 발급하는 일회용 코드로 세션을 넘겨 선택한 프로필을 유지합니다. 서버 메모리에 저장하므로 서버 재시작이나 접속 세션 만료 시 초기화됩니다. 새 탭은 별도 세션입니다.

방 생성·입장은 최소 10칩이 필요합니다. 정산 후 10칩 미만이면 결과를 표시한 뒤 2초 후 대기실로 내보내며, 0칩은 **꺼져 쉐끼야 ㅋㅋ** 모달을 표시합니다. 충전 전 방에 들어가려 하면 **님은 잔고 충전부터 하고오셔야 할듯ㅎㅎ** 모달을 표시합니다. 자동 충전은 없습니다.

방 만들기 아래의 **잔고 충전하기**는 현재 잔고와 관계없이 반복해서 이용할 수 있습니다. 제시 문장을 직접 입력해 완성할 때마다 1,000칩을 지급하고 충전액은 누적 손익에서 제외합니다. 문장 선택·복사는 가능하고 입력창의 붙여넣기·드롭은 차단하며 **ㅋㅋ 복붙이 되겠노?^^** 안내를 띄웁니다. 서버도 문장과 일회용 충전 요청을 확인해 중복 지급을 막습니다.

패는 서버에서 섞고 사용자별로 따로 전송합니다. 상대 패와 족보는 응답 데이터에서도 가립니다. 중도 입장자는 떠난 사람의 패를 물려받지 않습니다. 최종 비교 때 다이하지 않은 패만 공개하며, 모두 다이해서 이긴 경우 상대 패를 공개하지 않습니다. 차례·잔액·베팅 금액·이전 판 요청을 서버에서 검증합니다. 연결이 끊기면 복귀 유예 동안 베팅을 멈추고, 시간 초과·퇴장은 해당 자리의 다이로 처리합니다. 나머지 사람들은 계속 진행합니다.

## 자동 테스트

```powershell
npm test
```

또는 프로젝트 폴더에서 `node --test`를 실행하세요. 오목 판정과 실시간 대전, 섯다 족보·4인 베팅·칩 보존·올인 정산·패 비공개·호스트 위임·게임 간 격리를 검증합니다. jsdom으로 실제 화면 코드를 실행해 프로필·초대·복귀·오목 착수와 4인 섯다의 패 아래 족보·베팅·결과·채팅을 검증합니다. jsdom은 브라우저의 시각적 배치와 애니메이션 재생 품질을 검증하지는 않습니다.

## 서버에서 실행하기

이 프로젝트는 **계속 실행되는 Node.js 프로세스 한 개**가 필요합니다. 정적 파일 호스팅만으로는 대전이 동작하지 않습니다.

```powershell
$env:PORT = '3000'
node server.js
```

기본 바인딩은 `0.0.0.0`입니다. 같은 네트워크의 다른 기기는 서버 PC의 IP와 포트로 접속할 수 있습니다. 운영 환경에서는 도메인 앞에 HTTPS 리버스 프록시를 두고 `/socket.io/`의 WebSocket 업그레이드 및 폴링 요청을 이 Node 서버로 전달하세요. `Host`를 보존해야 같은 출처 확인이 통과합니다. 프로세스 수는 1개로 유지하세요.

## 저장과 범위

- 방과 대국은 서버 재시작 시 초기화됩니다. 방은 30분 동안 활동이 없으면 닫힙니다.
- 선택한 프로필 ID는 `localStorage`에, 탭별 복귀 토큰과 대기 중인 초대 코드는 `sessionStorage`에 저장합니다. 이름과 아바타는 프로필 ID에 고정되며, 클라이언트가 다른 이름이나 아바타를 보내도 서버의 고정값을 적용합니다. 브라우저 저장이 제한되어도 대국은 가능하지만 새로고침 후 복귀는 보장되지 않습니다.
- 이름 선택은 회원 인증이 아닙니다. 여러 사람이 같은 이름을 선택할 수 있으며, 각 탭의 게임 참가자는 별도 세션으로 구분합니다. 서버도 허용된 이름만 적용하고, 방 안에서는 프로필 변경을 막습니다.
- 공개 방 목록, 비공개 초대 방, 착수 확인, 마지막 수·승리 연결 표시, 기권, 나가기, 재대국을 지원합니다.
- 회원가입, 전적, 랭킹, 이미지 업로드, 자동 매칭, 렌주룰은 이번 버전에 포함하지 않았습니다.
- 게스트 세션과 기본 요청 제한을 적용했습니다. 대규모 공개 서비스로 확장할 때는 서버 간 상태 공유, IP별 접속 제한과 운영 모니터링을 추가해야 합니다.

## 도트 아바타

아바타는 `public/assets/avatars/`의 투명 PNG를 사용합니다. 주찬은 초록색 갓파 캐릭터, 경후는 진격의 거인의 초대형 거인, 강희는 근육맨 캐릭터, 용환은 진한 눈썹·헝클어진 갈색 머리·주황색 옷깃의 캐릭터입니다. 동현은 노란 아프로·흰 선글라스·파란 재킷, 지원은 주황색 가시 몸체·흰 장갑·파란 신발, 민서는 초록색 참이슬 병입니다. 모두 정면의 굵은 도트 스타일로 높이를 맞췄으며 프로필 선택·홈·대기실·대국에 동일하게 표시합니다.

강희는 이마의 `肉` 표시와 빨간 레슬링 복장·부츠를 갖춘 근육맨 캐릭터입니다. 다른 두 아바타와 어울리도록 픽셀을 굵게 하고 근육·명암 묘사를 단순화했으며, 몸통과 다리를 짧게 줄여 전체 높이를 맞췄습니다. 이름과 아바타의 연결은 그대로 고정됩니다.

생성 방식과 사용한 프롬프트는 `assets/avatar-prompts.json`에 기록합니다.
